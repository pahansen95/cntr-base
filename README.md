# Container Base

This project provides multiple base functionalities for building containers or similiar bundles.

The following subprojects provide various features geared towards simplifying software development:

| Name | Description |
| ---- | ----------- |
| [EventBus](./EventBus) | Basic IPC backed by the Kernel & a Filesystem |
| [ServiceManager](./ServiceManager) | A very basic plugin based service manager that can serve as an init system |
